The 'Morphoné' folder is the Web-Audio interactive application to fully experience our experiments.

It is ready to be used on pc computers.

To avoid OS web-audio blocking procedures, Here are the instructions for Mac users:

1 - Open the Terminal app on your Mac.

2 - Type cd  (include a space after "cd"), drag and drop the Morphoné folder into the Terminal window, and press Enter.

3 - Type the following command and press Enter:

Bash
python3 -m http.server 8000

4 - Open Chrome or Firefox and visit the address:
http://localhost:8000

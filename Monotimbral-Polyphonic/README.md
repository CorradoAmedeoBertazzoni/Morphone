# Morphoné: Monotimbral-Polyphonic Timbre Transfer and Morphing

## Overview
We have done a first experiment of Monotimbral-Polyphonic transfer using Basic Pitch on the mono, untreated original recording(s) (refer to the interactive jupiter notebook version published here),
then loading the '.mid' resulting files in the DAW of choice and choosing appropriate realistic sound libraries for the destination instrument(s).

This Read Me file will be updated after any Monotimbral-Polyphonic Project will be added.
